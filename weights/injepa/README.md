# InJepa E12 checkpoint

Load `epoch_0012.pt` with the evaluation commands in the [repository README](../../README.md). Its training configuration is recorded in `e12_training_config.json`.

This checkpoint was trained on frozen V-JEPA features of [StreamVLN R2R/RxR trajectories](https://huggingface.co/datasets/cywan/StreamVLN-Trajectory-Data), whose visual observations originate from [Matterport3D](https://niessner.github.io/Matterport/).
